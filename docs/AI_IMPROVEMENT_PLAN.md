## 🚀 2. 인공지능 기반 서비스 고도화 4대 핵심 개선 과제

### 🎯 [과제 1] 상황 감지 맞춤 프롬프트 엔지니어링 (Context-Aware Prompt Tuning)
- **개요**: 단순히 수치와 태그만 전달하는 것에 그치지 않고, 사용자의 **접속 시간대(아침/오후/야간)** 및 **배터리 수치 구간**을 컨텍스트로 추가 주입.
- **세부 개선 내용**:
  - **야간(22시~05시)** 접속 시: 수면 유도 및 마인드풀니스 위주의 따뜻한 고양이 톤 적용.
  - **극단 수치(0~9%)** 입력 시: `[🚨 긴급 응급 충전 모드]` 페르소나 활성화, 10초 미션을 초간단 호흡법으로 자동 조정.
  - **구현 파일**: `app/api/prescribe/route.ts` (Dynamic System Prompt Builder)

---

### ⚡ [과제 2] Gemini AI 스트리밍 연동 & 초저지연 반응성 (Streaming & Latency Optimization)
- **개요**: PRD 성공 조건(P95 2.5초 이내)을 뛰어넘는 **체감 반응속도 극대화**.
- **세부 개선 내용**:
  - Gemini REST API `streamGenerateContent` 또는 SSE(Server-Sent Events) 파이프라인 도입.
  - 클라이언트에서 처방전이 완성되길 기다리지 않고, **고양이 응원 메시지가 실시간 타자기(Typing) 애니메이션**으로 렌더링되도록 구현.
  - **구현 파일**: `app/api/prescribe/route.ts`, `app/page.tsx`

---

### 💬 [과제 3] 1초 대화형 고양이 코치 꼬리질문 (Interactive AI Coach Follow-up)
- **개요**: 단발성 처방전 수령 후 사용자가 아쉬움을 느끼지 않도록 1회성 퀵 질문 인터랙션 제공.
- **세부 개선 내용**:
  - 처방 카드 하단에 퀵 질문 칩 3종 배치 (예: *"1분 루틴 더 쉽게 하는 법?"*, *"지금 잠이 안 와냥"*, *"응원 한 번 더 해줘!"*).
  - 클릭 시 로그인/세션 없이 1초 만에 Gemini API가 고양이 코치 페르소나로 즉시 위트 있는 추가 답변 제공.
  - **구현 파일**: `components/result-card.tsx`, `app/api/chat/route.ts` (NEW)

---

### 🎵 [과제 4] 멀티모달 & 앰비언트 AI 사운드 큐레이션 (Multimodal Sound & Visual Generation)
- **개요**: 처방 결과의 `recommended_bgm` 추천 텍스트를 실시간 앰비언스 사운드 플레이어와 연결.
- **세부 개선 내용**:
  - Gemini가 추천한 BGM 무드(예: *Lo-fi 재즈*, *빗소리*, *숲속 바람 소리*)에 대응하는 웹 브라우저 내 오디오 사운드트랙 플레이어 매핑.
  - 고양이 캐릭터 주변에 BGM 무드 아이콘 및 배경 파티클 동적 렌더링.
- **구현 파일**: `components/ambient-player.tsx` (NEW), `lib/battery.ts`
